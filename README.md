# Pokémon Search App 🔍🧬

This is a [Next.js](https://nextjs.org) project built with TypeScript and GraphQL using Apollo Client.  
It allows users to search for Pokémon by name and view details such as their types, attacks, and evolutions.

---

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
# or
yarn install
```
